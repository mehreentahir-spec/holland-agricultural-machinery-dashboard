# 🚜 Holland Agricultural Machinery Dashboard

An interactive data analysis and visualization project for a Holland-based agricultural machinery showroom.

## 📊 Project Overview

This project analyzes agricultural machinery inventory, including tractors and harvesting equipment. The dashboard provides an interactive way to explore machinery by category, brand, price, working hours, condition, and stock status.

## ✨ Dashboard Features

* 🚜 Machinery inventory overview
* 🏭 Brand-wise analysis
* 📦 Inventory status analysis
* 💰 Price analysis
* ⏱️ Working hours analysis
* 🔧 Condition-wise analysis
* 🔎 Interactive machinery search
* 🎛️ Category, brand, and status filters
* 📈 Interactive charts and visualizations
* 📋 Detailed machinery inventory table
* 🌐 Offline interactive HTML dashboard

## 🚀 How to Use

1. Download or clone this repository.
2. Open the interactive HTML dashboard from the `dashboard` folder.
3. Use the filters and search box to explore the machinery inventory.
4. Open the Jupyter Notebook to view the Python-based data analysis.

This project was created as a practical **Data Analysis and Data Visualization portfolio project**, demonstrating the process of transforming raw machinery data into an interactive analytical dashboard.
