# 🚜 Holland Agricultural Machinery Dashboard

An interactive agricultural machinery data analysis and visualization project developed for a Holland-based agricultural machinery showroom.

🔗 **[🚀 Open Live Interactive Dashboard](https://mehreentahir-spec.github.io/holland-agricultural-machinery-dashboard/)**


## 📊 Project Overview

This project analyzes a dataset of agricultural machinery, including tractors and harvesting equipment.

The interactive dashboard provides a clear overview of machinery inventory and allows users to explore the data through filters, charts, KPIs, and an interactive inventory table.

The project demonstrates the complete process of transforming raw machinery data into meaningful insights and an interactive dashboard.


## ✨ Dashboard Features

- 🚜 Total machinery inventory overview
- 🏭 Brand-wise machinery analysis
- 📦 Inventory status analysis
- 💰 Price and inventory value analysis
- ⏱️ Working hours analysis
- 🔧 Machinery condition analysis
- 🔎 Interactive machinery search
- 🎛️ Category, brand, and status filters
- 📈 Interactive data visualizations
- 📋 Detailed machinery inventory table
- 🔄 Reset filters functionality
- 🌐 Interactive HTML dashboard


## 📌 Key Performance Indicators

The dashboard includes important KPIs such as:

- **Total Machines**
- **Total Inventory Value**
- **Average Machinery Price**
- **Average Working Hours**
- **Machines Currently in Stock**


## 📈 Visualizations

The dashboard contains several interactive visualizations:

- 🚜 Machines by Category
- 🏭 Top Machinery Brands
- 💰 Average Price by Category
- 📦 Inventory Status
- 📈 Price vs Working Hours
- 🔧 Average Price by Condition


## 🎛️ Interactive Filters

Users can interact with the dashboard using:

- **Category Filter**
- **Brand Filter**
- **Status Filter**
- **Machinery Search**

The charts, KPIs, and inventory table update according to the selected filters.
